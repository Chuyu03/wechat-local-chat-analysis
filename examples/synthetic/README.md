# Synthetic example data

Everything in this directory is fictional and was written solely to demonstrate the local file formats. It contains no captured screenshot, real contact, real chat excerpt, machine path, or production output.

- `manifest.json` shows schema v1 with workspace-relative paths.
- `ocr/000001.json` and `ocr/000002.json` show normalized PaddleOCR 3-style results for two different synthetic screenshots.
- `messages.jsonl` deliberately repeats the same synthetic text across two sources. The records remain separate and are marked for possible scroll-overlap review.

The dates in these fixtures are deliberately future fictional dates. Do not treat this directory as evidence from a real WeChat session.
